# Codex Blackfyre

---

## ✨ Overview

**Codex Blackfyre** is a personal blog and content review platform dedicated to exploring the vast world of online creators, games, tech, and culture. More than a simple blog, this project aspires to become a living compendium—a place where insightful reviews, original character lore, and thoughtful guides coexist, reflecting the ever-evolving interests of its creator.

- **Frontend:** Astro (React), 
- **Deployment:** Vercel, GitHub Pages, or similar

---

## 📚 Features

- **Tech Guides:** Practical tips on Linux, gaming setups, programming, and digital productivity.
- **Game Reviews:** Focused, honest takes on cult classics and hidden gems.
